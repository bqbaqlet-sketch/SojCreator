# СӨЖ генераторы — сайт

Сайт: пайдаланушы тақырып/аты-жөн/топ енгізеді → Gemini (тегін API)
қазақша мәтін жазады → сервер сол мәтінді ТИКК үлгісіндегі
(логотип, шрифттер, титул парағы) `.docx` файлға жинайды.

## Құрылымы

```
backend/
  server.js          — Express сервер, /api/generate маршруты
  systemPrompt.js     — Gemini-ге берілетін нұсқаулық (мәтін стилін осында өзгертесің)
  buildDocx.js        — .docx құжатын жинайтын код (шрифт, өлшем, титул, колонтитул)
  assets/logo.jpeg    — колледж логотипі (өзіңдікіне ауыстыруға болады)
  public/index.html   — форма (фронтенд)
  .env.example        — API кілтінің үлгісі
```

## 1. Жергілікті жерде іске қосу

1. [Node.js](https://nodejs.org) орнат (18+ нұсқасы).
2. Терминалда:
   ```
   cd backend
   npm install
   cp .env.example .env
   ```
3. `.env` файлын аш, `GEMINI_API_KEY=` жолына өз кілтіңді қой.
   Кілтті мына жерден тегін аласың: https://aistudio.google.com/app/apikey
   (Google аккаунтпен кіріп, "Create API key" басу жеткілікті.)
4. Серверді қос:
   ```
   npm start
   ```
5. Браузерде аш: **http://localhost:3000**

## 2. Тегін хостингке шығару (сайт нағыз интернетте жұмыс істеуі үшін)

Бұл жоба backend (Node.js сервер) қажет ететіндіктен, оны тек
HTML/JS ретінде емес, толық сервер қолдайтын хостингке шығару керек.
Тегін нұсқалары:

- **Render.com** (ұсынылады, ең қарапайымы):
  1. Жобаны GitHub-қа жүкте (жаңа репозиторий жасап, осы `backend`
     қалтаны сонда салу).
  2. render.com сайтында "New → Web Service" бас, GitHub репозиторийіңді
     таңда.
  3. Build command: `npm install`, Start command: `npm start`.
  4. "Environment" бөлімінде `GEMINI_API_KEY` айнымалысын қос (мәні —
     өз кілтің).
  5. Деплой аяқталған соң саған `https://сенің-атың.onrender.com`
     сияқты сілтеме береді — сайт содан жұмыс істейді.

- **Railway.app** — дәл осылай, тегін лимитімен.
- **Cyclic.sh** / **Fly.io** — балама тегін нұсқалар.

⚠️ **Маңызды:** `GEMINI_API_KEY`-ды ешқашан фронтендке (HTML/JS ішіне)
жазба және GitHub-қа `.env` файлымен бірге жүктеме — кілтті хостингтің
"Environment Variables" бөлімінде ғана сақта. `.env` файлы GitHub-қа
түспеуі үшін `.gitignore` файлын қос (төменде берілген).

## 3. Мәтін стилін өзгерту

`systemPrompt.js` файлындағы нұсқаулықты өзгертсең, Gemini басқаша
жазады — мысалы, көлемін, стилін, тілін (қазақ/орыс) немесе
құрылымын (неше ішкі тақырыпша) осы жерден баптайсың.

## 4. Дизайнды өзгерту

`buildDocx.js` ішінде:
- `SZ` объектісі — қаріп өлшемдері (half-point: 24=12pt, 28=14pt...)
- `FONT` — қаріп атауы (қазір Times New Roman)
- `assets/logo.jpeg` — өз логотипіңмен ауыстыруға болады (файл атауы
  сол қалпында қалуы керек)
